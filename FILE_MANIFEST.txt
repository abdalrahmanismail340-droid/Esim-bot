🔄 DATA FLOW
═══════════════════════════════════════════════════════════════════════════════

CUSTOMER:
  /refund
    ↓
  refund_amount() → REFUND_AMOUNT state
    ↓
  refund_id() → REFUND_ID_OR_ADDR state
    ↓
  refund_reason() ✅ FIXED BUG → REFUND_REASON state
    ↓
  refund_confirm() → REFUND_CONFIRM state
    ↓
  db.create_refund_request()
    ↓
  notify_admins()
    ↓
  "تم إرسال الطلب"

ADMIN:
  /admin → 💳 طلبات الاسترجاع
    ↓
  refunds_panel() → List all pending
    ↓
  refund_detail() → View single request
    ↓
  [✅ Approve] OR [❌ Reject]
    ↓
  refund_approve_start() → Enter Txid
    ↓
  refund_txid_save() → db.process_refund("approved")
    ↓
  Notify customer + Log action
    ↓
  OR
    ↓
  refund_reject_start() → Enter reason
    ↓
  refund_note_save() → db.add_balance() + db.process_refund("rejected")
    ↓
  Notify customer + Log action + Restore balance

🐛 WHAT WAS FIXED
═══════════════════════════════════════════════════════════════════════════════

BUG: "حصل خطأ، حاول ثاني" error at refund step 3

ROOT CAUSE:
  In handlers_user.py, refund_reason() function:
  
  BEFORE (broken):
  ────────────────
    user_id = context.user_data.pop("refund_uid")      # KeyError if missing!
    amount = context.user_data.pop("refund_amount")
    binance_id = context.user_data.pop("refund_binance_id")

  AFTER (fixed):
  ──────────────
    user_id = context.user_data.pop("refund_uid", None)      # Safe with default
    amount = context.user_data.pop("refund_amount", None)
    binance_id = context.user_data.pop("refund_binance_id", None)
    
    if not user_id or amount is None or not binance_id:
        await update.message.reply_text("❌ حصل خطأ في البيانات...")
        return ConversationHandler.END

LOCATION: handlers_user.py, lines ~450-480
